# Bellevue 公共泉：形体依据与当前施工

施工对象为既有源点 `wvz_brunnen.466`，Brunnen 59，LV95 `[2683606.575,1246801.044996]`。不移动真实泉位。

[市艺术品登记](https://kunstbestand.stadt-zuerich.ch/de/collection/item/556/)将其识别为 Otto Münch 的“三个坐在鱼上的男孩”喷泉，给出约4×4m的槽体、槽体高0.78m、连雕塑总高1.07m，单组雕塑约0.29×0.63×0.25m。这是针对已知缺口的一次补查，不重新调查街区。

两个官方目录对年份和金属描述不一致：供水表记1937、铸铜；艺术品目录记1938/1939安置、镀铬白金属。暂时并列保留，不能直接用绿色铜锈代替实物外观。Castione槽体由供水表确认；具体石纹、抛磨、边缘与水渍需通过近景判断。

[图片分类页](https://commons.wikimedia.org/wiki/Category:Bellevuebrunnen)的初次候选下载失败；随后已实际查看Roland Fischer / Roland zh的三张CC BY-SA3.0历史图：2010整体、2010铸件及2011-03-23溢流细节。精确URL、作者、许可、哈希见 `sources/references/bellevue_fountain59/commons_receipt.json`。官方图库图片仍返回403，未绕过。所需形体参考已足够，停止重复搜集；照片没有用于纹理，也不冒充2026同步街景。

最新原生018r3已构建石盆、支座、三组可编辑的推断铸件、六股解析水流、闭合水体、穿孔溢流罩和接池底的立管，共68对象。已实际检查多角度渲染并修复池沿UV剪切、薄板鱼鳍与金属盖放射高光。雕塑具体解剖和背面仍为近似。几何接地、水体闭合及孔洞检查已通过，资料/身份不变；导出、水面播放、真实近景与日常使用分开验收，不添加研究任务。

导出发现旧MixRGB的颜色常量被遗漏而图片像素原样保留。已将导出副本等价转换为RGBA Mix，重新导出后确认水位线因子、金属粗糙度图、IOR及81帧水面轨迹保留。原生材质不变。浏览器工具尚不可用，因此不据数据核验宣称实时或自然使用完成。
