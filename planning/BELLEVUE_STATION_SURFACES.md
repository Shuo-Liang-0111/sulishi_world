# Bellevue 站区路面与设施：当前依据和施工边界

本批站区调查范围为 LV95 [2683500,1246765,2683650,1246910]，约150×145m；G1整体边界保持不变。只把其中有依据的道路面和对应钢轨推进为实体，不能把这个矩形当作已修订完成。

- 2025年末AV道路11个要素，在本批范围内合计约8446.28m²。站台、其他人行岛和建筑另有独立边界。路面不能跨越这些边界平铺。
- AV中的`Bahngeleise`表示轨道轴线。[联邦测绘说明4.30](https://www.cadastre-manual.admin.ch/dam/de/sd-web/1w2YzPJppDIF/Richtlinie-Detaillierungsgrad-EO-de.pdf)明确这一点。不能直接把一条轴线当一条实体钢轨。
- [VBZ基础设施](https://data.stadt-zuerich.ch/dataset/geo_vbz_infrastruktur_ogd)另外提供逐根钢轨，近区190条记录。与轴线距离中位数0.4984m，已在正射影像上实际对照；本轮沿真实钢轨线建模，不重新生成简化路网。[官方Flexity资料](https://www.stadt-zuerich.ch/content/dam/vbz/de/die-vbz/medien/medienmitteilungen/2018/Faktenblatt%20Flexity.pdf)给出1000mm轨距，但钢轨数据线代表轨头何处尚未独立确证，不能拿中心线距离当轨头内侧的精密验收值。
- 已取得18个VBZ图层，每层保留请求、范围、时间、SHA256及源属性于 `sources/features/vbz`。`haltestellen_haltebalken`是点位，不能误称为完整站台边界；设施外形、朝向单位、用途与现状仍需逐项实景核对。`strecke_weichensignal`本范围返回0条，不代表不存在其他类型信号。
- 官方对接触网可靠性/质量另有较低评级，道岔点位属性也可能注明位置质量未知。不得因为它们是官方数据就自动接受为精确实体。

路面高程：从摄影网格中提取近水平、落在道路内部的低位候选面，按0.7m网格均衡得到2451个候选。用稳健区域二次坡面剔除659个残差超过20cm的候选；1792个保留点用于55邻域拟合，并用区域梯度约束稀疏/狭窄位置的外推。最终2m格按同一对角线拆成分片平面，路面、轨头与轨槽都使用同一三角平面。这套高程仍是可视核查用的推断平顺路面，不是施工测量；候选、排除掩码和原始资源均保留。早期元数据内“bilinear”字样已被后附的piecewise-planar说明取代，不能按双线性曲面理解当前007r1/r2几何。

G1_007r1近景已实际看过，路缘缺侧面使背景穿透；原生射线已确认。现有站台沿边缘的摄影推断高差中位数约26cm、最大约38cm，两个半米采样位置低于推断路面约1cm；见 `platform_join.json`，这两个坡端位置仍需修正，不能认定通行合格。007r2补实体边缘及22cm宽矿物质顶带，保留精确平面边界，未修改室内孔洞。22cm宽、1.2m分缝和具体材料均是照片约束下的推断。

实拍显示至少南侧轨道区为混凝土铺面并有板缝、盖板。007r3/r4已依据SWISSIMAGE和运营方照片分区：约6625.56m²沥青、1382.64m²混凝土、2.17m²凹缝。东侧首轮矩形错误侵入站台，已改按实际弯曲轴线40430/40432/40434/40435约束后裁剪真实道路；遮挡区铺面宽度仍是推断。8mm缝宽、3mm凹深、3.6m板长为推断，所有分区沿原共同坡面，不改路网。粗露骨料材料经实际渲染拒用为轨区铺面，改为更符合照片的细骨料浇筑混凝土；原路缘保留粗矿物质表面。

007r5按11条官方过街步行连接，在其附近逐条提取并查看SWISSIMAGE里的70条可见黄色标线。精确沿路面三角坡面建模、抬高1.5mm为推断涂层，独立对象保留route_id；不是地面照片贴片。遮挡导致缺失的黄线、磨损、导盲与完整过街可达性还未验收。数据及叠图在`derived/bellevue/transport/crossings_*`；原生和实时西侧人眼机位都明确暴露了邻接树团、岛体和首层破碎的问题。

钢轨槽有实际下凹底面和侧壁。65mm轨头、165mm总槽宽、35mm深度暂为明确标注的剖面推断；道岔尖轨、辙叉及护轨槽尚需修订，当前不作车辆动力学几何验收。

施工顺序：核查高程与摄影差分 → 调整路缘/站台坡端 → 准确恢复过街与导盲铺装 → 对照来源点补回站台设施 → 多方向近景 → 同版本导出与自然步行检查。道路照片中的旧车辆随地面替换移除，不能作为新的实体车辆，也不能靠新增装饰掩盖接缝。

图证：`derived/bellevue/transport/source_overlay.png`、`vbz_rail_overlay.png`、`road_height_support.png` 均已实际查看。它们是施工依据，不是已完成场景。
